## GitHub Avatar setzen

Die API hier kann den Repo-/Org-Avatar nicht schreiben. Manuell:

1. Datei [`logo/sbl-avatar.png`](./logo/sbl-avatar.png) herunterladen  
2. GitHub → Repository **SBL-Web** → *Settings* → *General* → Social preview / bzw. Organisation → *Settings* → Avatar  
3. Optional Social Preview: [`exports/github-social.png`](./exports/github-social.png)
