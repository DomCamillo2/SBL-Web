# Referenz-Mapping: msb-ai.de → Archetyp `service-local-b2b`

Öffentliche Beobachtung der Site [msb-ai.de](https://msb-ai.de) als strukturelle Blaupause — keine 1:1-Kopie von Copy oder Assets.

## First Viewport

| Element | Beobachtung | Factory-Regel |
|---------|-------------|---------------|
| Brand | MSB / Automation klar präsent | Brand hero-level, nicht nur Nav |
| Headline | „Automation mit Menschenverstand.“ | Eine Aussage |
| Support | Weniger manuelle Arbeit … | Ein Satz |
| CTA | Prozess prüfen lassen | Eine Primärhandlung |
| Extra | Region + 3-Schritt-Mini | Lokalität + Vertrauensmechanik, kein Stat-Spam |

## Section Sequence (Home)

1. Hero + lokale Einordnung  
2. Erfahrung / Kontext (ehrlicher Proof)  
3. Schmerzpunkte (Alltagsverluste)  
4. Themen (Leistungsbereiche)  
5. Beispiele (Startprozesse)  
6. Vorgehen (Phasen mit Ergebnis)  
7. Team  
8. Closing CTA  

## Content Patterns to Reuse

- **Phasen mit Ergebnis:** jede Phase hat Input → Output → Entscheidung  
- **Menschliche Kontrolle** als wiederkehrendes Vertrauensmotiv  
- **Anti-Hype:** keine „Revolutionize“-Claims; konkrete Abläufe  
- **Disclaimer-fähiger Proof:** Erfahrungshintergrund statt erfundener Kundenlogos  

## Underpage Pattern (`/vorgehen`)

Dieselbe Phasenlogik, vertieft + FAQ + Verantwortung/Datenschutz-Block.  
→ Archetyp sollte „Method page“ als optionales Modul haben.

## What NOT to copy blindly

- Spezifische Team-Bios und Firmennamen  
- Exakte Wortlaute  
- Visuelles Design 1:1 (eigene Tokens erzwingen)  

## Suggested tokens direction for similar clients

Nicht MSB-Farben klonen — Prinzip:

- Ruhige neutrale Flächen + ein entschiedener Akzent außerhalb AI-Hue-Band  
- Expressives Display + lesbares Body  
- Editorial Spacing, keine Dashboard-Kartenästhetik
